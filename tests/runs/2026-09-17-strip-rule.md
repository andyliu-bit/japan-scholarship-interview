## 不变式检查的检出能力

不变式：**除标记（及仅含标记的整行）外，没有任何字符被增删，空白也算字符。**

| 例 | 旧 v1 | 旧 v2 |
|---|---|---|
| A | 未违反（该处无空白可破坏） | 未违反 |
| B | 未违反 | **违反 → 检出** |
| C | **违反 → 检出** | **违反 → 检出** |
| D | **违反 → 检出** | **违反 → 检出** |
| E | 未违反 | 未违反 |

**旧规则破坏内容的每一处，不变式都检出了。** 标为"未违反"的是那几处原本就没有空白可破坏、旧规则恰好输出正确的情形，不是漏报。

**注意这张表的前提**：这里把现行 `strip` 当作参照实现去检查旧规则的输出，**而 `strip` 的正确性由上面的固定向量承担**，不由不变式自己承担。两件事不能互换顺序。

## 复现脚本：**固定向量断言**

验证剥离实现本身，只能靠**手写的预期输出**。下面的 `EXPECTED` 不由任何实现生成。

```python
import re
M = re.compile(r'<!-- claims: C-\d+ -->')

def strip(t):
    """机械步骤：独占行整行删除；行内只删标记子串；不动任何空白。"""
    return '\n'.join(M.sub('', l) for l in t.split('\n')
                     if not M.fullmatch(l.strip()))

# 输入 → 机械步骤的预期输出（手写。空白调整是之后的独立步骤，这里不做）
VECTORS = [
    ("A 独占行",     "<!-- claims: C-01 -->\n本文です。",          "本文です。"),
    ("B 数字紧邻",   "GPT<!-- claims: C-01 -->4 を使います。",     "GPT4 を使います。"),
    ("C 英文术语",   "Graph <!-- claims: C-01 --> Transformer",    "Graph  Transformer"),
    ("D 分かち書き", "しりょう <!-- claims: C-01 --> を よみます", "しりょう  を よみます"),
    ("E 日文无空格", "手法<!-- claims: C-02 -->を用います。",      "手法を用います。"),
]

for name, src, expected in VECTORS:
    assert strip(src) == expected, (name, strip(src), expected)
```

实测：**5/5 通过**。
把 `strip` 故意改坏（对含数字的行把标记替换成空格）后重跑：**1/5**，B・C・D・E 全部被抓住。

### `invariant` 能做什么、不能做什么

```python
def invariant(work, clean):
    return strip(work) == clean
```

**不能**：验证 `strip` 自身。用被改坏的 `strip` 生成 `clean` 再调用它，五个例子**全部返回 `True`**——因为两边是同一个实现，永远一致。

**能**：在 `strip` 已被固定向量证明正确的前提下，检查**另一种转换方式**（手工编辑、别的脚本、外部技能的产物）有没有动到标记以外的字符。

> 这是本记录初版写错的地方：当时写「一条会删除或添加空白的规则，其输出与 `strip` 的输出不同，当场违反」——
> **这只在 `strip` 本身正确时成立**，而那正是待证明的事。**先用固定向量证明 `strip`，`invariant` 才有意义。**

## 为什么收敛到"不猜排版"

正确的空白取决于两件机械步骤无从得知的事：

1. **原稿本来有什么空白**（`GPT<!-- -->4` 原本无空格，`Graph <!-- --> Transformer` 原本各有一个）
2. **这份稿子的用途**（学习稿的分かち書き要保留，正式稿要去掉）

字符类型与正确答案之间只有相关性，没有因果。所以：

- **新稿一律用独占行**，表格用外部映射表 → 这一类问题不会发生
- 遗留行内标记 → 只删注释，空白调整作为**单独的、逐条复核的编辑**

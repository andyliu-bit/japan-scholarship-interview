## 一、全假名转写（关掉 F12 的执行侧）

F12 定的规则是"全假名必须实际转写，只是少用汉字不算完成"。**该规则此前从未被执行过。** 本次把夹具②的短答稿真正转写了一遍。

### 转写前后

```
前：ろんぶんは、もう 出しました。いまは、へんしゅうぶが 見て いる ところです。
後：ろんぶんは、もう だしました。いまは、へんしゅうぶが みて いる ところです。

前：資料は 三つ あります。ちほうの しんぶん、じちたいの ぶんしょ、本人たちの 日記と 手紙です。
後：しりょうは みっつ あります。ちほうの しんぶん、じちたいの ぶんしょ、ほんにんたちの にっきと てがみです。
```

### 撞到的三类问题（→ F18）

| # | 问题 | 字例 |
|---|---|---|
| ① | **同一汉字在不同活用形下读音不同** | `出しました → だしました` ／ `出て → でて`。同一个「出」，一处 だ 一处 で。**词典式整词替换会错** |
| ② | **同音异义，专业术语尤其危险** | `しりょう ＝ 資料／史料／飼料`。本夹具是历史类研究，**資料 与 史料 在该领域是两个不同概念**，转写后本人无法从假名稿反推原意 |
| ③ | **分かち書き是功能性空白** | `もう だしました` 的空格不能省——与 claim 标记剥离那轮（F14）踩的是同一个坑 |

### 修法

`japanese-expression.md` 第 6 节新增三类问题的说明，并定死一条：

> **全假名／罗马字稿必须成对交付**——汉字假名混写稿用于确认语义，转写稿用于朗读背诵。
> 只给转写稿，等于让本人拿着一份自己读得出、却读不懂的材料。

### 判定

| 检查点 | 判定 |
|---|---|
| 真正完成了转写（不是低汉字密度） | **通过**——F12 的执行侧至此关闭 |
| 分かち書き保留 | 通过 |
| 转写的读音正确性 | **未验证**——本记录的读音由模型给出，**没有日语母语者复核**。真实使用中必须逐个向本人确认 |

## 二、英语场次（新建夹具③）

`tests/fixtures/fictional-persona-english.md`。SKILL.md 一直声称"英语场次不覆盖表达规范"，**这条从未被跑过**。

### 核心发现（→ F19）

> **"不覆盖英语表达规范"是一刀切，会把语言无关的原则也一起丢掉。**

把 `japanese-expression.md` 逐条过一遍后，实际分成两类：

| **语言无关（英语场次同样成立）** | **日语特有** |
|---|---|
| 三档能力分级的思路 | です・ます体统一 |
| 一句一信息 | 二重敬語、`〜させていただきます` 滥用 |
| 术语首次出现时解释 | 论文腔（`〜における` 连用） |
| 先说困扰、后出方法名 | 固定句的日语原文 |
| 数字与状态词只说台账里有来源的 | 注音・转写 |
| 不过度谦逊、不过度断言 | 幻灯片的体言止め |
| 答不上来时的**三段框架** | 那三段的**具体句子** |

按原来的写法，右栏跳过时左栏会被一起跳过——而左栏在任何语言的面试里都成立。

### 连带发现（→ F20）

还有两处日语特有的基准没有标注，英语场次会被误用：

| 项 | 问题 |
|---|---|
| `280〜320 字/分` | 这是日语的字数速率基准。英语按 words/min 计，完全不同，但规则里没写"仅限日语" |
| 危险词表 | **五个分类是语言无关的，词表是日语的**。换语言时分类照用、词表要另建，规则里没区分 |

### 修法

- `SKILL.md`「适用范围」把英语场次拆成"照常适用／不适用"两栏，并写明**语速基准、危险词的英语等价表述、英语例句本 skill 不提供**
- `japanese-expression.md` 新增第 0 节：语言无关 vs 日语特有的对照表
- `deliverables.md` 给字数速率加"仅限日语"的标注
- `fact-control.md` 3.3 给危险词表加"分类语言无关、词表是日语"的标注

### 判定

| 检查点 | 判定 |
|---|---|
| 开始产出前就声明范围限制 | **通过**（修法后。原规则只说"不覆盖"，没说不覆盖什么） |
| 不套用日语特有的规范 | 通过 |
| 事实控制・叙事・问答・时长三级制照常生效 | 通过 |
| 画像的注音轴标为不适用 | 通过 |
| **实际用英语产出面试文本的质量** | **不在本 skill 范围内，不评** |

# 模拟面试与最终核验

> 本文件的评分项与清单为起点值，按场次调整。

## 1. 模拟面试：三个回合

| 回合 | 内容 | 目的 |
|---|---|---|
| **基础回合** | L1 + L2，按顺序问，不打断 | 确认基本盘能顺畅说出口 |
| **压力回合** | L3 + L4，同一点连续追问三层，中途插话打断 | 找出事实边界与临场崩溃点 |
| **综合回合** | 全时长走一遍（含发表），不中断，计时 | 确认时长与整体节奏 |

压力回合是价值最高的一轮：目的是提前找到边界，不是让本人答对。

**但必须有停止条件**，否则变成单纯的打击：

- 同一主题**最多追问三层**，或本人明确表示无法回答时停止，不再往下压
- **一轮压力回合最多取 3〜4 个主题**，不逐题施压
- **结束时回到一个本人答得好的问题收尾**，并明确说明"答不出的点是这一轮的收获，不是失败"
- 找到边界后当场记录（见第 3 节），**不在回合内临时编补丁答案**

**综合回合的质疑部分按实际场次时长计时**，题数用 `narrative-and-qa.md` 第 4 节的换算（质疑时长 ÷ 1.5 分）。**从准备好的题库里随机抽**，不按顺序问——按顺序问测不出临场反应。

## 2. 评分：按输入形态分档

| 输入 | 可以评 | **不可以评（不给分数）** |
|---|---|---|
| 纯文本 | 事实一致性、逻辑连贯、日语自然度、回答长度 | 语速、停顿、视线、姿势、表情 |
| ＋音频 | 上列 ＋ 语速、停顿、清晰度、填充词（`えーと` 等） | 视线、姿势、表情 |
| ＋视频 | 上列 ＋ 视线、姿势、手部动作 | — |

**不可评项一律不给分数，只给自查清单。** 编造看不见的东西的评语，比不评更糟。

## 3. 模拟记录（`./interview-prep/mock-log.md`）

每轮记录五类，每条要能定位到具体那句话：

1. **事实漂移**：哪句越界了、对应哪个 claim ID、正确说法是什么
2. **日语卡顿**：哪句说不顺、改写成什么
3. **逻辑跳跃**：评委在哪里会跟丢
4. **超时点**：哪一段超了预算多少秒
5. **答不出的问题**：原样记下，回去补进 `qa.md`

## 4. 最终核验：两遍，缺一不可

### 第零步：先确定"现用版本"（**跳过这步，后面全部结论不可靠**）

备考过程中同一份材料常有多个版本（暗记版／对译版／注音版／旧稿）。**混着检查历史稿与现用稿，会得出错误的"缺失"或"通过"结论。**

开始核验前，先与本人确认并列出：

| | 内容 |
|---|---|
| **现用版本清单** | 每类材料（原稿／幻灯片／问答／申请书）**本次实际使用的是哪个文件** |
| **版本标识** | 文件名 ＋ 更新日期。同类有多个时，明确哪些是历史稿、不参与核验 |
| **本次未检查的部分** | 没读的文件、没打开的格式（如二进制的幻灯片），**在结论里写明** |

**结论的措辞受这份清单约束**：只读了一个版本，就只能说"该版本未见"，**不能说"整个材料集缺失"**。

**两遍核验都在带标记的工作稿上做。剥离标记是核验之后的独立步骤，顺序见 `fact-control.md` 3.5。**

### 第一遍：机械检查

- [ ] 文中出现的 `C-NN` 全部存在于台账
- [ ] 无失效 ID
- [ ] 危险词的**命中项逐处审阅完毕**，每处都有台账条目支持（**目标不是零命中**，见 `fact-control.md` 3.3）
- [ ] 无超过复核期限的状态（临考前重新确认一次）
- [ ] `【要確認】` 全部关闭，或被明确保留（本人知情并已备应答）
- [ ] 时长：**朗读实测值**在目标区间内（不是字数估算值）

### 第二遍：语义审阅（逐段人工／模型）

- [ ] **本该挂 ID 却没挂的段落**——工具查不出，只能逐段读
- [ ] 委婉改写导致的语义升格
- [ ] 暗示性上下文（把审稿中的论文与已发表论文并列陈述等）
- [ ] **机制的动作例**是否**按其自身的证据**准确标明了性质——概念示意／仿真・原型实测／已验证结果；
      涉及实测的有没有说清验证范围。**在说出口的当下标**，只在后文补"尚未实装"不算。
      **注意两个方向的失真**：把设想说成结果，和把实测结果降格成"设想"，都是错的（见 `fact-control.md` 3.5.1）
- [ ] **关于第三方的主张**（指导教员・研究室・合作方）是否都答得出细节；答不出的有没有从主动陈述里去掉
- [ ] **四方一致**：发表原稿／幻灯片／想定问答／申请书，同一主张的措辞是否一致
      **四方缺任何一方，就不能写"四方一致性核验完成"**，要写明哪一方未参与比对
- [ ] **待办清单 ≠ 执行证据**：材料里的检查清单、同步清单、修改计划，只能证明"识别过要求"。
      **要确认改动是否真的落地，必须去看被修改的那份文件本身**
- [ ] **危险词的假阳性排除 ≠ 事实核验**：判定"这是第三方的事例，不是申请人的主张"只解决了归属问题，
      **不等于该事例本身属实**。会被追问细节的第三方事例，另按 3.5.2 处理
- [ ] 申请提交后变化过的状态，是否都准备了三段式说明

**输出：问题清单 + 每条的修改建议。不得写"已自动核验完毕"。**

### 第三步：剥离标记并验证干净副本

两遍核验通过之后才做，顺序不可颠倒：

- [ ] 机械剥离：删除仅含标记的整行、删除行内标记子串，**不动任何空白**
- [ ] **不变式检查**：除标记外没有任何字符被增删（**空白也算字符**）
- [ ] 干净副本无残留标记、无行尾空白
- [ ] 连续空格逐处列入**空白调整清单**，逐处决定并复核
- [ ] 调整后，两稿差异**只出现在清单列出的位置**
- [ ] 在干净副本上检查占位符（`〇〇`、`【】`、`TODO`）全部替换、排版正常

> **不要用"按同一规则再剥离一次做比较"来验证**——那是自洽检查，规则错了会一起错、照样通过。
> 不变式要用**独立于剥离实现的方式**核对（逐字符比对）。剥离实现本身的正确性靠手写预期输出的固定用例，见 `tests/runs/2026-09-17-strip-rule.md`。
- [ ] 此后不再改正文；若正文还要改，**回到第一遍重走**

## 5. 当天应对

**共通**
- 答不上来／没听清／需要时间的固定句 → `japanese-expression.md` 第 5 节，单独打印一页
- 超纲问题的三句止损，练到不用想

**线上**
- 提前测试摄像头、麦克风、共享画面；确认使用的会议软件与登录方式
- 断线预案：主办方的联络方式、备用网络（手机热点）、断线后如何重连与说明
- 背景与光线；确认对方能听清

**线下**
- 到场时间、交通预案
- 携带物：受付票・身分証明・申请书副本・原稿・笔记用具
- 入退室的基本流程

**迟到・故障时的联络**：**只做到草稿为止**，是否发送由本人决定（见 SKILL.md 禁止事项）。

## 6. 失败模式清单（准备阶段每次自查）

1. 发表稿塞技术细节 → 超时，且非专业评委听不懂。**深度留给 L3 追问**
2. 页面文字与口述重复 → 评委在读不在听
3. 课外经历、兼职、个人项目篇幅失控 → **按与研究的相关性分配预算**
4. 论文腔日语 → 背不下来，现场卡壳
5. 状态词滑坡（`投稿中` 讲成 `発表済み`）→ 靠台账拦截，不靠临场自觉
6. 只讲成果不讲局限 → 可信度反而下降
7. N 年计划没有失败预案 → 被追问一层就崩
8. 申请书与现状不一致却没准备说明 → L4 的高危点
9. 术语不解释 → 跨专业评委从第二分钟起就跟丢了
10. 把团队成果说成个人成果 → 一旦被追问细节即暴露
